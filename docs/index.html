4. Năm đặc tính điện toán đám mây NIST

1. On-demand Self-service - Tự phục vụ theo yêu cầu

Người dùng có thể tự tạo môi trường lập trình GitHub Codespaces thông qua nút Create codespace mà không cần yêu cầu quản trị viên cấp phát máy.

2. Broad Network Access - Truy cập mạng rộng

API được cung cấp thông qua URL của GitHub Codespaces. Người dùng có thể truy cập từ trình duyệt trên các thiết bị có kết nối Internet khi cổng được thiết lập Public.

3. Resource Pooling - Gộp tài nguyên

GitHub sử dụng hạ tầng tài nguyên dùng chung để cung cấp môi trường Codespaces cho nhiều người dùng. Mỗi người dùng được cấp phát tài nguyên theo cấu hình của môi trường.

4. Rapid Elasticity - Co giãn nhanh

Người dùng có thể tạo, dừng và thay đổi cấu hình môi trường Codespaces khi nhu cầu sử dụng thay đổi. Tài nguyên có thể được cấp phát theo nhu cầu.

5. Measured Service - Dịch vụ đo lường được

GitHub theo dõi mức sử dụng Codespaces thông qua số lượng core-giờ. Người dùng có thể xem thông tin sử dụng tại Settings → Billing → Usage.

5. Kết luận

Qua bài thực hành, sinh viên đã biết cách tạo môi trường lập trình trên nền tảng đám mây bằng GitHub Codespaces.

Xây dựng thành công API Hello Cloud sử dụng Node.js và Express.js để trả về thông tin máy chủ dưới dạng JSON.

Đồng thời, thực hiện so sánh môi trường máy tính cá nhân với môi trường đám mây và nhận diện năm đặc tính cơ bản của điện toán đám mây theo tiêu chuẩn NIST.
